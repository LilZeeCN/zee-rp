# 自由画布：设计上限与 AI 友好性纲要

> 本文件是后续所有改动的**验收依据**。任何"改完更好看了"的说法，必须落回这里的指标或外部试用判定，否则不算完成。
> 状态：v1（2026-10-27）。随 RSI 迭代追加，不覆盖历史结论。

---

## 0. 定位

不是「AI 版 Figma」，是**「AI 的设计交付流水线」**：不比谁画得好看，比谁能把设计**送到可交付状态**，并且**可证明**。

Figma 是**读侧 AI 友好**（AI 读设计→产代码，Dev Mode MCP 成熟）；写侧要靠插件桥，操作是副作用式的——没有 revision、没有 CAS、没有幂等、没有编译失败可回滚。这个结构性差异决定了竞争维度：

| 维度 | Figma | 本产品 |
|---|---|---|
| 源文件 | 云端二进制文档 | `.rp1` 纯文本：可 diff / git / CI / 回滚 |
| 写入 | 插件桥，副作用 | 事务 + 幂等键 + 未受影响页面哈希核验 |
| 可验证 | 无客观校验层 | 三零 / 几何 1px / 字体保留 / 事件覆盖 |
| 终点 | 云端设计文件 | 原生可编辑 `.rp`（Axure 存盘·关闭·重开可过） |

## 1. 质量五层与评分表

| 层 | 内容 | 对手 | 判定方式 |
|---|---|---|---|
| **L1 视觉完成度** | 字阶节奏、留白呼吸、层级对比、精致度 | Figma+人（他们赢） | 代理指标 + 人眼 |
| **L2 结构一致性** | token 使用、4/8 栅格、组件漂移、重名 | **本产品赢** | 全自动 |
| **L3 完整性** | 空/错/载态、长文本、边界数据 | **本产品赢** | 全自动 |
| **L4 可交付性** | 原生可编辑率、事件闭合、下游可接 | **本产品赢** | 全自动 |
| **L5 产品判断** | 主任务、主操作、信息层级 | 都不稳 | 盲测任务完成率 |

**现实约束**：交付场景的返工 70% 来自 L2/L3/L4，不是"不够惊艳"。因此总分权重按 L2 25% / L3 20% / L4 25% / L1 25% / L5 5% 计。

### L1 达标线（够用即可交付，不追求"更好"）

| 指标 | 达标线 | 度量 |
|---|---|---|
| 字阶比 | 1.2 ≤ r ≤ 1.5，且全页最多 4 级 | 相邻字号比值 |
| 间距栅格 | ≥90% 间距落在 4/8 网格 | 间距集合取模 |
| 留白占比 | 30%–45% | 空白面积 / 画布面积 |
| 正文对比度 | ≥4.5:1（大字 ≥3:1） | WCAG 相对亮度 |
| 单屏色相数 | ≤3 主色相 + 1 强调 | 色相直方图 |
| 反 slop 命中 | **0** | 负样本规则库 |

四项全过 → L1 判定"达标"；未过 → 不许宣称完成。

## 2. 五根支柱

### P1 可评判性（最高优先）
现在 review 拒绝自评审美分——诚实但等于没反馈，迭代被"人工评审带宽"锁死。补三种**可复现的相对判断**：

1. **锚点驱动**：每个题材 3 个锚点 + 排版配方（栅格/字阶/留白比/色相分布/层级深度）。输出"你的字阶 1.25，锚点 1.33；留白 32% vs 41%"，而不是"不够高级"。
2. **差分评审**：`compareWith: revision`，v1/v2 并排 + 变化区高亮。
3. **反 slop 检测**：等距三卡、紫渐变、居中空话标题、图标+圆角方块、纯 CSS 无素材。命中即拒。

**语料护城河**：锚点来自**本项目历史页面与评审记录**（私有语料，Figma 拿不到），不是互联网美图。

### P2 语义与约束
节点带 `role`（hero/nav/primary-action/empty-state）与可校验约束：触控 ≥44、对比度、主操作全页唯一、每列表必有空态、信息密度上限。**约束必须是机器可验的**，否则等于注释。

### P3 批量与收敛
一次 N 个变体（主题×密度×字阶×配色网格）→ 按 P1 指标自动排序 → 缩略拼图 → 选 2 个细化。**不赌单发命中率，取分布上尾。**

### P4 关系谓词编辑
AI 的手不是鼠标，是关系：`align left to #title`、`move by [0,8]`、`distribute gap=12`、`swap order`、`"hero 右下角那个按钮"` → 候选解析 + 确认。把"locate→edit→locate→edit"压成一轮。

### P5 导出预算前置
`filter` 被丢、渐变被栅格化——设计时必须可见。给工程级保真预算：`native 87% / rasterized 9% / dropped 4%`，并在 review 中列"只能当参考图"的节点。

## 3. 明确不做

| 不做 | 原因 |
|---|---|
| 多人实时协同 / CRDT | AI 无并发光标需求；并行的是工程不是人 |
| 插件市场 | AI 本身就是插件 |
| 钢笔/布尔运算 | AI 不手绘；矢量走 SVG 导入 + 栅格化边界声明 |
| 审美总分 | 不可信，会训练模型讨好分数 |
| 把图层面板做成 Figma | 那是给人找节点的；AI 要的是 `locate` + role |

| 支柱 | 工具 | 状态 |
|---|---|---|
| P1 可评判性 | `studio_design_metrics`：字阶比 / 4px 栅格 / 留白 / 色相 / 主次比 / 6 条反 slop | ✅ 有回归 |
| P1 锚点驱动 | `studio_design_anchors`：`extract` 只锚达标页，配方含结构量（主图占比/栏宽/对齐基线/间距节奏）；`compare` 输出百分比正确的偏离 | ✅ 有回归 |
| P3 批量与收敛 | `studio_design_explore`：四轴**铺开采样**（非循环前缀），按「未达标项→硬伤→离门槛距离→提示→命令条数」排序，入选变体直接给可提交 commands | ✅ 有回归 |
| P2 语义约束 | `role` + 三项关系检查（主操作唯一 / 点击区 / 空态覆盖） | ✅ 有回归 |
| A3 行过滤 | RP/1 `@repeater where=`（编译期）+ Studio `repeaterSetFilter`（运行时） | ✅ 有回归 |
| P4 关系谓词编辑 | `align/move by` 等 | ⬜ 未做（已有空间定位后端的 `W_LAYOUT_IGNORES_POSITION` 提示） |
| P5 导出预算前置 | 保真预算 | ⬜ 未做（导出报告已有分类，未前置到画布） |

判断标准没变：**工具只能说"哪里错了、怎么改"，不能说"我觉得好看"**。`studio_design_explore` 的排序规则写在返回里，任何人都能复算。

## 4. RSI 闭环（递归自我改进）

```
想法 → 变体生成 → 指标评分(自动) → 试用反馈(外部子代理)
   ↑                                        ↓
   └──────── 只保留指标↑且未被试用否决的改动 ←┘
```

规则：
1. **每轮必须留痕**：`docs/rsi-log.md` 记「假设 / 改动 / 指标 before-after / 试用结论 / 保留或回滚」。
2. **指标回退即回滚**：任一 L1 指标或 L2/L4 检查变差，直接 revert，不辩论。
3. **外部否决优先**：低思考强度新子代理说"难用"，视为失败，即便指标变好。
4. **不自我认证**：作者不给自己打分；"好用"只能由未参与实现的试用者给出。
5. **可回退**：任何破坏性改动前先 tag + 备份；回滚脚本必须真跑过一次。

## 6. 设计即艺术：三条硬要求

1. **限制优于自由**：模型自由发挥出来的就是 slop。所有版式收敛到「栅格 × 字阶 × 间距刻度 × 色板」四元组内搜索。
2. **素材优先于装饰**：一张真图 + 留白，胜过十个渐变圆角。缺素材时用排版建立层次，不用装饰填空白。
3. **一个屏只有一个主角**：主标题、主操作、主图三选一做视觉焦点，其余全部降级。做不到就说明信息架构没想清楚。
