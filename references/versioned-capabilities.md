# RP/1 编译器词表与版本

当前安装包版本 `v0.4.5`。本表由 RP/1 编译器公开词表生成。视觉属性的宿主证据见 [四消费面对照](surface-capabilities-matrix.md)。

## 语法版本

- `v0.4.4` 支持同一事件块混排动作、连续条件、嵌套分支和等待后的续体。
- `v0.4.5` 增加原生表单动作短写、同一事件内内联 JSON 动作、弃用提示及带前置守卫的事务。
