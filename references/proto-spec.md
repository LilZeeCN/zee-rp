## 3. 自动布局容器与基础原语 (`type`)

### 3.1 容器与动态面板

| `type` | 关键属性 | 说明 |
|---|---|---|
| `box` | `name`, `layout` (`"column" \| "row" \| "stack" \| "grid"`), `columns`, `columnGap`, `rowGap`, `w`, `h`, `flex`, `padding` (`number` 或 `[v,h]` 或 `[t,r,b,l]`), `gap`, `align` (`"start" \| "center" \| "end" \| "stretch"`), `fill`, `stroke`, `radius`, `isGroup` (有子节点时默认 `true` 发射原生 `Axure:Layer`), `bgName`, `children` | 核心 Flexbox / Grid 自动布局容器；若设置 `fill` 或 `stroke`，自动生成底层背景矩形 `bgName`；在 `row` 容器中未显式指定 `h` 且 `flex > 0` 的子容器会自动拉齐父容器内高 |
| `card` | `name`, `title`, `subtitle`, `rightText`, `w`, `h`, `flex`, `padding`, `gap`, `fill`, `stroke`, `radius`, `children` | 带可选标题栏与默认卡片圆角/边框的语义化容器，自动发射原生 `Axure:Layer` |
| `dynamic-panel` | `name`, `x`, `y`, `w`, `h`, `states: [{ "name", "prefix", "device", "canvas", "root" }]` | 原生 `DynamicPanel`；每个 state 独立编译为 `.axvg.json` 并通过 `fillPanelState` 灌入对应状态 |

### 3.1.1 尺寸关键字 (`fill` / `hug` / `auto`) 与 `grid` 布局契约

`w` / `h` 在容器与所有叶子原语上均接受四种取值：

| 取值 | 语义 |
|---|---|
| `number` | 固定像素（如 `320`） |
| `"fill"` | 占满父容器该轴可用空间；在主轴上等价于 `flex: 1`，可与显式 `flex: N` 兄弟共存并按权重均分剩余空间（余数精确补偿给末个弹性子项）；在交叉轴上撑满父容器内高/内宽 |
| `"hug"` | 按内容尺寸自适应收缩（`measure_node` 阶段按子内容 + `padding` 精确包裹，支持 `row`、`column`、`grid`） |
| `"auto"` | 使用组件自然测量尺寸 |

`layout` 接受 `"row"` / `"column"` / `"stack"` / `"grid"`。
`grid` 支持 `columns`（默认 `2`）、`columnGap`（默认取 `gap`）、`rowGap`（默认取 `gap`）：子元件按 `columns` 列自动折行并均分列宽 `cell_w = (inner_w - (columns - 1) * columnGap) // columns`，每行高度按该行最高子项自适应。

```json
{ "type": "box", "name": "grp-cards", "layout": "grid", "columns": 3, "w": "fill", "h": "hug", "gap": 16, "padding": 16,
  "isGroup": true, "bgName": "bg-grp-cards", "fill": "$surface",
  "children": [
    { "type": "button", "name": "btn-1", "text": "网格项 1", "h": 36 },
    { "type": "button", "name": "btn-2", "text": "网格项 2", "h": 36 },
    { "type": "button", "name": "btn-3", "text": "网格项 3", "h": 36 }
  ]
}
```

**`bindDetail` 命名契约（v3.1 起自动对齐，无需手写）**：

`set-text` 模式会向目标页的 `mobile-detail-view` 写入
`<prefix>-badge-type` / `-item-title` / `-attr-loc` / `-item-pubtime` / `-item-meta` / `-attr-cat` / `-desc-para-l1` 等元件。

`<prefix>` 的解析优先级（v3.1 已自动处理，**不再需要手写 `targetPrefix`**）：
1. `bindDetail.targetPrefix`（显式指定，最高优先级）
2. 目标页 `mobile-detail-view` 节点自身的 `prefix`
3. 该节点最近祖先的 `prefix`
4. **目标页的 `slug`**（与 `expand_declarative_tree(root, prefix=p_slug)` 一致）

> **v3.1 之前**：`<prefix>` 硬编码回退为 `"view"`。若详情页 `slug` 不是 `view`（如 `detail`），
> 4~16 个 `set-text` 目标会全部悬空（`interaction_dangling_targets > 0`），
> 而文档未说明这条隐含契约。现已自动探测，`dangling=0`。

**`bindDetail` 两种工作模式**：
1. **默认首卡同步 + 面板状态展开 (`mode: "panel-states"`)**：
   - 自动将 `cards[0].detail` 同步给目标页首个 `mobile-detail-view`，确保卡片一与详情页默认展示完全一致；
   - 若设置 `"expandStates": true`，编译器自动在目标 `DynamicPanel` 中为每张卡片克隆独立的详情状态，并在卡片点击时写入 `SetGlobalVariableValue(OnLoadVariable, cid)` + 跨页 `link`，同时在目标页 `OnPageLoad` 按 `OnLoadVariable` 切换到对应卡片的详情状态。
2. **页面根元件文本动态改写 (`mode: "set-text"`)**：
   - 当详情页未使用动态面板（`mobile-detail-view` 直接位于页面根部）或同页主从联动时，自动生成 `OnLoadVariable` + `OnPageLoad` 条件分支，调用 `set-text` 将被点击卡片的 `badge / itemTitle / location / pubTime / category / holder / description` 动态写入详情页对应标签。

## 6. 两级审计门禁 (`audit-report.json`)

编译器将审计门禁分为两级，兼顾结构安全性与快速原型探索自由度：

1. **结构与安全门禁 (`structural_gates`，10 项硬失败，不达标始终 `exit 1`)**：
   - `no_text_overlap`: 文本重叠数 `== 0`
   - `no_text_clip`: 文本裁切数 `== 0`
   - `no_missing_glyphs`: `PingFang.ttc` 零墨迹高度 (`bb[3]-bb[1]==0`) 豆腐块/幽灵字形数 `== 0`
   - `no_kinsoku_violation`: 段落折行行首出现禁则标点（如 `，。、；：！？）】》`）违规数 `== 0`
   - `no_container_overflow`: 子节点超出父容器边界 (>1px) 溢出数 `== 0`
   - `no_box_overlap`: 线性布局容器内兄弟节点重叠数 `== 0`
   - `no_duplicate_names`: 同页/同状态内重名元件数 `== 0`
   - `semantic_naming_ok`: 语义化命名覆盖率 `>= 90%`
   - `group_coverage_ok`: 原生 `Axure:Layer` 编组覆盖率 `>= 80%`
   - `interaction_targets_ok`: 悬空交互触发器/目标数 `== 0`
2. **审美与令牌门禁 (`aesthetic_gates`，默认输出 `warnings[]` 并 `exit 0`；传 `--strict-audit` 时升级为 `exit 1`)**：
   - `alignment_ok`: 亚像素对齐误差 `<= 1.0px`
   - `spacing_ok`: 间距与圆角令牌合规率 `>= 95%`
   - `font_ok`: 字阶与字重合规率 `>= 90%`
   - `whitespace_ok`: 留白率处于领域合理区间（Web `30%~55%`，Mobile/Doc `12%~88%`，小画布测试页 `5%~95%`）
   - `color_ok`: 单页色彩总数 `<= 18`
   - `four_state_ok`: 含 `table` 的动态面板具备 `default/empty/loading/error` 四态；无适用对象时为 N/A（百分比 null，适用分母为 0），不表示检查通过 100%

审计逐页面、面板状态、Repeater 行模板分别运行；`audit-report.json` 的 scenes 与 sceneCoverage 给出覆盖清单和分母。各场景互斥检查，失败带 sceneId 和元件位置并进入总报告。文字裁切与重叠同时考虑实际墨迹和声明盒；固定高度不足会报错。报告不能外推为 Axure 宿主像素或交互验证。
