# 栖羽设计参考

这是用户认可的自然观察应用视觉标杆。source.json 是可编辑源，assets 保留原图与派生图，media-recipes.json 记录裁切配方，previews 是原生预览参考。benchmark.json 解释设计选择、适用范围和限制；manifest.json 固定参考身份。

学习页面目的、素材构图、信息层级和状态组织，不把纸色、森林绿或固定坐标作为所有题材的默认值。工具型与学习型任务当前没有已获认可的视觉标杆。

照片均来自 Frank-2.0 的普通翠鸟 CC0 照片；详见 [图片来源](CREDITS.md)。源文件和截图用于本项目的创作参考，未宣称任意平台和数据量都已验收。
