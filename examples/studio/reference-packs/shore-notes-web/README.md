# 岸线 · 图文观察手记

鲜明的不对称首页将文字与大照片并置；文章用 620px 连续正文、侧边照片与旁注形成三种阅读密度。首页进入文章，正文完整可读；收藏、取消与上下两个返回入口均可操作。

照片来源及许可见 `CREDITS.md`；`assets/` 保留原图和裁切图，`media/recipes/` 与 `media-recipes.json` 保留确定性配方。`source.json` 只使用相对资源路径。手记为原创观察习作，不声称照片摄于文中现场。字体使用本机 Songti SC、PingFang SC、Avenir Next、Menlo。此作品为代理创作候选，未获用户审美认可。
