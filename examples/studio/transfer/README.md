# 三道迁移题：候选研究

这三套每套3页的源用于验证同一画布是否能根据任务组织不同的信息层级；视觉选择尚待用户判断，不列为用户认可标杆。

| 题目 | 主要决定 | 完整流程 |
| --- | --- | --- |
| 翼间 · 自然观察特展 | 编辑式标题、摄影与展览时间先建立内容期待 | 展览→导览→预约凭证→返回 |
| 借物 · 实验室设备 | 库存与设备列表优先，缩小装饰，几何图形区分种类 | 相机→借期→借用凭证→返回 |
| 拾知 · 每日一张 | 先回忆再揭示答案，留出阅读与思考空间 | 今日→问题→翻面→完成→返回 |

`build.mjs` 重建3份便携 JSON 源与摄影素材；生成后可分别用 `studio start --project /abs/new-project --source /abs/equipment.json` 打开。按钮、文字、几何和照片保持各自可编辑节点。

摄影来自 Frank-2.0 的普通翠鸟照片，CC0 1.0；完整来源和授权链接见 [栖羽素材说明](../qiyu-field-notes/CREDITS.md)。`sp_photo.jpg`、`jr_photo.jpg` 是该原图的裁切衍生。设备图形为源中的基础几何，未使用商业图标包。场馆、预约、库存与借用为原型演示数据；没有接入真实预约或借用服务。

同题基线使用现有探索模板的第一方案，输入相同的标题、设备/课程等必备内容；业务期望相同，节点定位按实际布局映射。只有首页改变，详情与结果页相同，用于隔离首页设计路径的影响；不能据此声称完整产品的盲测获胜。

验证入口：`verification/design-workflow/run-transfer.mjs`，输出相同视口截图、原生 `.rp`、业务日志、负对照及匿名 A/B 比较页。人工视觉验收待定；研究不证明其他模型能自动复现相同设计质量。
