# README 视觉素材

`hero.svg` 是为 zee-rp 原创的编译工作台插画，采用源码、页面树、选择框和交互连线表达项目的原生编辑特点，MIT。

`qiyu-*.png` 是「栖羽」观鸟原型的编译预览，演示 9 页移动端原型的实际布局。它们展示已生成的原生工程；照片识别、路线和统计为演示数据。26 项浏览器交互断言在本机实际 Axure 预览通过；圆角修复后的复验见 [反馈复验](../../docs/authoring-feedback-20261025.md)。预览不作为生成耗时、通用质量或第三方服务可用性的证明。
