# README 视觉素材

`cover.svg` 是为 zee-rp 原创的新版品牌与工作流插画，采用炭黑、暖白、荧光绿及可编辑选框表现 RP/1 → Studio → Axure。标题字形已转为路径，适配 GitHub 图片显示；属于示意插画，MIT。

既有 `hero.svg` 为旧版原创编译工作台插画，保留其引用兼容，MIT。

`showcase.png` 重新排版下方三张真实编译预览，统一手机框并保留完整屏幕内容，不改变界面文字或结果。画面含下述 CC BY-SA 4.0 摄影的派生预览，整张展示图按 CC BY-SA 4.0 提供。

`studio.png` 是当前 Studio 的真实界面截图，展示另一版六页「栖羽」的文字选择、图层和几何属性；演示工程显式声明既有整屏stack容器，清除无意义的布局告警，未修改产品UI。照片为下述 Frank-2.0 的 CC0 翠鸟；原创界面与排版按 MIT。它展示画布编辑，不冒充 Axure GUI 截图或编译耗时证据。

`qiyu-*.png` 是「栖羽」观鸟原型的编译预览，演示 9 页移动端原型的实际布局。它们展示已生成的原生工程；照片识别、路线和统计为演示数据。26 项浏览器交互断言在本机实际 Axure 预览通过；圆角修复后的复验见 [反馈复验](../../docs/authoring-feedback-20261025.md)。预览不作为生成耗时、通用质量或第三方服务可用性的证明。
